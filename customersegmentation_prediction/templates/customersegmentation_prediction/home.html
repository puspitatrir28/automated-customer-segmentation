How the System Works

1. Data Integration

Extracts transaction data from the DVD Rental database through an automated ETL process.

2. AI Clustering

Utilizes the K-Means Clustering algorithm to group customers into 3 primary segments.

3. Business Action

The dashboard provides strategic promotion recommendations based on individual customer profiles in real-time.
